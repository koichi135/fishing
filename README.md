# 🎣 ミノー ルアーアクション 3Dシミュレーター

釣り用ルアー(ミノー)の水中アクションをブラウザ上で3Dシミュレーションするツールです。
Three.js を使用したビルド不要の静的サイトで、GitHub Pages でそのまま公開できます。

## 機能

- **ウォブリング / ウィグリング**: リトリーブ速度に応じてロール・ヨーの振動周波数と振幅が変化
- **潜行シミュレーション**: リップの潜行レンジ設定と速度に応じてルアーが潜る
- **ルアータイプ**: フローティング(停止で浮上)/ サスペンド / シンキング を切り替え可能
- **トゥイッチ**: ボタンで瞬間的なダートアクション
- **リトリーブ操作**: 巻き/停止の切り替え、再キャスト、軌跡表示
- **3D視点操作**: ドラッグで回転、ホイールでズーム(カメラはルアーを自動追従)

## 操作方法

| 操作 | 内容 |
|---|---|
| リトリーブ速度 | 巻き速度 (0.2〜3.0 m/s) |
| 潜行レンジ | リップによる最大潜行深度 (0.3〜3.5 m) |
| アクション強さ | ウォブリングの振幅 |
| ■ 停止 / ▶ リトリーブ | 巻きの開始・停止(ストップ&ゴー) |
| トゥイッチ | ロッドを煽るダートアクション |
| 再キャスト | ルアーを初期位置(18m先)に戻す |

## ローカルで実行

ビルド不要です。`index.html` をそのままブラウザで開くか、簡易サーバーで配信します:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

※ Three.js は CDN (jsdelivr) から読み込むため、インターネット接続が必要です。

## GitHub Pages で公開する

このリポジトリには GitHub Actions によるデプロイワークフロー
(`.github/workflows/deploy-pages.yml`)が含まれています。

1. このブランチを `main` にマージ(または push)する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を **GitHub Actions** に設定する
4. `main` への push で自動的にデプロイされ、`https://<ユーザー名>.github.io/fishing/` で公開されます

(Actions を使わない場合は、Source を「Deploy from a branch」にして `main` / root を選んでも公開できます)

## 技術構成

- [Three.js](https://threejs.org/) r160(importmap 経由で CDN 読み込み)
- 単一の `index.html`(HTML / CSS / JS すべて含む、ビルドツール不使用)
- 簡易物理モデル: 速度追従(一次遅れ)、速度依存の潜行深度、正弦波によるロール/ヨー振動、浮力によるフローティング挙動
