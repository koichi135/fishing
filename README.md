# 🎣 深海の入り江 - WebGPU 釣りゲーム

ブラウザで遊べる3D釣りゲームです。舞台は昆布の森・岩のアーチ・沈没船・クジラの尾びれの石像が
沈む幻想的な入り江。キャストからファイト・キャッチまでの一連の流れを、スマホのタッチ操作と PC の
両方に対応して実装しています。**WebGPU で直接描画**し、エンジン・ライブラリ・テクスチャ・モデル
ファイルは一切使わない(すべてプロシージャル生成)単一の `index.html` です。

## 遊び方(ゲームの流れ)

1. **キャスト** — 「長押しでキャスト」ボタンを押すとパワーゲージが往復します。
   離した瞬間のパワーで飛距離(8〜34m)が決まります。
2. **リトリーブ(水中カメラ)** — 着水後は水中視点に切り替わります。
   「リール」ボタンの長押しで巻き、「トゥイッチ」で誘いを入れます。
   ドラッグで視点回転、ピンチでズーム。
3. **アタリ** — ルアーに興味を持った魚が追尾し、食いつくと画面に「アワセ!!」が表示されます
   (バイブレーション・効果音つき)。
4. **フッキング** — 表示中(約0.85秒)に画面をタップするとフッキング成功。遅れると逃げられます。
5. **ファイト** — テンションゲージを見ながらのやり取り。
   魚が走っている間に巻くとテンションが上がり、**ゲージが振り切れるとラインブレイク**。
   逆に緩めすぎるとフックが外れます。魚が止まったら巻いて距離を詰めましょう。
6. **リザルト** — 岸まで寄せればキャッチ! 魚種・サイズ・重さと自己記録
   (localStorage に保存)が表示されます。

## 攻略のヒント

- 魚は **1.0〜1.6 m/s 前後のリトリーブ速度** と強めのウォブリングに反応しやすい
- 追尾中の **トゥイッチ** や **ストップ&ゴー(巻きを止めた瞬間)** はバイト率が大きく上がる
- 大物(ランカーシーバス)ほど引きが強く、走っている間に巻くと一瞬でラインブレイクする
- 魚種はサイズで変化: セイゴ (〜39cm) / フッコ (40〜59cm) / スズキ (60〜79cm) / ランカーシーバス (80cm〜)

## 操作まとめ

| 操作 | 内容 |
|---|---|
| キャストボタン長押し → 離す | パワーを溜めてキャスト |
| リールボタン長押し | 巻き取り(リトリーブ / ファイト共通) |
| トゥイッチ | ダートアクションで誘う |
| アタリ中に画面タップ | アワセ(フッキング) |
| ドラッグ / ピンチ | 水中カメラの視点回転 / ズーム |
| ⚙ ボタン | リトリーブ速度・潜行レンジ・アクション強さ・ルアータイプの調整 |

PCでは Space(キャスト/リール/アワセ)と X(トゥイッチ)でも操作できます。

### フリーカメラ(観察モード)

🎥 ボタンまたは **F** キーで切り替え。クリックでポインタロックし、
**WASD** 移動 / **マウス** 視点 / **Q・E** 下降・上昇 / **Shift** 加速。

## ローカルで実行

ビルド不要です。`index.html` をそのままブラウザで開くか、簡易サーバーで配信します:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

※ WebGPU 対応ブラウザ(Chrome / Edge 113+、Safari 26+ など)が必要です。外部通信は行いません。

### 計測・検証用 URL パラメータ

| パラメータ | 内容 |
|---|---|
| `?perf` | フレーム時間と GPU 時間(timestamp-query)を画面左上に表示 |
| `?bench` | 60 秒のスクリプト化フライスルーを実行し、終了時に平均 / 99 パーセンタイル / 最大(フレーム・GPU)を表示・`console` 出力 |
| `?pose=0..5` | 検証用の固定カメラ 6 種 |
| `?scale=1` | 解像度倍率(既定: devicePixelRatio、上限 2 / タッチ端末 1.5) |

## GitHub Pages で公開する

このリポジトリには GitHub Actions によるデプロイワークフロー
(`.github/workflows/deploy-pages.yml`)が含まれています。

1. このブランチを `main` にマージ(または push)する
2. リポジトリの **Settings → Pages** を開く
3. **Source** を **GitHub Actions** に設定する
4. `main` への push で自動的にデプロイされ、`https://<ユーザー名>.github.io/fishing/` で公開されます

(Actions を使わない場合は、Source を「Deploy from a branch」にして `main` / root を選んでも公開できます)

## 技術構成

- WebGPU + WGSL(単一 `index.html`、ビルド不要・依存ゼロ)
- 描画: HDR(rgba16float)+ 4x MSAA → ポストパス(ゴッドレイのレイマーチ、ACES トーンマップ、ディザ)
- 水: 波の合成(頂点・法線)、上からはフレネル反射、下からはスネルの窓と全反射、深度に応じた波長別の吸収フォグ
- 光: 屈折した太陽方向から投影するアニメーションコースティクス、ゴッドレイ
- ジオメトリはすべて起動時に JS で生成(地形・岩・アーチ・昆布・植物・スポンジ・サンゴ・魚・マンタ・沈没船・石像)
- 昆布の揺れ・魚群・マンタの遊泳・泡・漂う粒子は頂点シェーダ内で時間から計算(CPU 負荷なし)
- メインループは毎フレームの JS アロケーションなし(行列・インスタンス・UI 文字列を事前確保)
- ゲーム: ステートマシン `ready → charge → flying → retrieve → bite → fight → result`、魚の AI(回遊・追尾・バイト・逃走)、ファイトのスタミナ / テンションモデル
- 効果音は WebAudio によるプロシージャル生成、アタリ・ヒット時は Vibration API で振動(対応端末のみ)
