# 🎣 BAYSIDE LURE FISHING — 湾岸ルアーフィッシング

ブラウザで遊べる本格3Dルアーフィッシングゲームです。スマホのタッチ操作向けに設計しています。
Three.js を使ったビルド不要の静的サイトで、GitHub Pages でそのまま公開できます。

## 遊び方

1. **時間帯を選ぶ** — 朝マズメ / 日中 / 夕マズメ / 夜。時間帯で空・光・水色だけでなく、釣れる魚や活性も変わります。
2. **キャスト** — 画面を左右にスワイプして狙いを定め、ボタン長押しでパワーを溜めて離します。
   白枠の**ジャストゾーン**で離すと、狙いどおりに遠くまで飛ぶ「ナイスキャスト」になります。
3. **リトリーブ(水中カメラ)** — 着水すると水中視点に切り替わります。「リール」長押しで巻き、「トゥイッチ」で誘います。
   ドラッグで視点回転、ピンチでズーム。「👁」で水上視点に切り替え。右上の**魚探**に魚影とボトムが映ります。
4. **アタリ → アワセ** — 魚が食いつくと「アワセ!!」が表示されます。リングが縮みきる前にタップ。
   速いほど PERFECT / GREAT / GOOD と判定が上がり、バレにくくなります。
5. **ファイト** — テンションゲージを見ながらやり取りします。
   - 魚が走っているときに巻くとテンションが上がり、限界を超えると**ラインブレイク**
   - 緩めすぎると**フックアウト**
   - 左下のパッドでロッドを倒せます。魚が走る向きと**逆**へ倒すと弱らせやすくなります
   - シーバス系は**エラ洗い**(ジャンプ)をします。「ロッドを寝かせろ!」をタップしていなしましょう
   - 右上の小窓は水中カメラ。タップでメイン画面と入れ替えられます
6. **ランディング → リザルト** — 足元まで寄せて弱らせるとタモ網でランディング。3Dで魚を眺められ、図鑑に記録されます。

### ナブラ
時々沖で小魚が追われて水面が沸き立ち、カモメが集まります(ナブラ)。その周りにキャストすると青物やシーバスのチャンス!
着水マーカーがオレンジになれば射程内です。

### 魚種(8種)
シーバス(セイゴ/フッコ/スズキ/ランカー)・ヒラスズキ・クロダイ・マダイ・ブリ(ワカシ/イナダ/ワラサ/ブリ)・ヒラメ・タチウオ・アジ

### ルアー(4種)
| ルアー | 特徴 | 得意な魚 |
|---|---|---|
| フローティングミノー | 巻くと約1.2m潜り、止めると浮く万能型 | シーバス、タチウオ |
| シンキングペンシル | ゆっくり沈むスローなS字スラローム | ヒラスズキ、ブリ |
| バイブレーション | 速く沈み強く振動。底を叩ける | クロダイ、マダイ、ヒラメ |
| ポッパー | 水面で水しぶきと音を立てる。水面炸裂! | ブリ、シーバス |

## 操作まとめ

| 操作 | スマホ | PC |
|---|---|---|
| 狙いの変更 | 画面を左右スワイプ | ドラッグ / A・D |
| キャスト | ボタン長押し→離す | Space 長押し→離す |
| リール | リールボタン長押し | Space 長押し |
| トゥイッチ | トゥイッチボタン | X |
| アワセ | 画面タップ | Space |
| ロッド操作 | 左下パッドを左右に | A・D / ←→ |
| エラ洗いをいなす | 「ロッドを寝かせろ!」をタップ | S / ↓ |
| 視点切替 | 👁 ボタン / 小窓タップ | V |

## 3D表現

- **空**: 大気散乱スカイ(Preetham)+ 手続き生成の雲、夜は星空・月・街明かりの光害
- **水面**: Gerstner 波、フレネル反射(空のキューブマップ)、太陽/月のグリッター、常夜灯の映り込み、
  着水・ヒット・ナブラで広がる波紋、水中から見上げたときのスネルの窓と全反射
- **水中**: 深さと光路長に応じた波長別の吸収(赤から消える)、コースティクス、ゴッドレイ、マリンスノー、泡
- **生き物**: 手続き生成の魚モデル(体形・ヒレ・模様を魚種ごとに生成)を頭から尾へ伝わる波でしならせて泳がせるシェーダ、
  虹彩(iridescence)の出る体表、ベイトの群れ、カモメ
- **港**: 桟橋・フジツボの付いた杭・常夜灯・岩礁・揺れる海藻・ヒトデ、防波堤と消波ブロック、灯台、対岸の街並みとクレーン、山並み、ボート、ブイ
- **ポストプロセス**: HDR + ブルーム、ACES トーンマップ、水中の揺らぎ・ビネット、ヒット時の色収差、テンション危険時の赤いビネット
- **演出**: 曲がるロッドとガイドを通るライン、回るリール、タモ網ランディング、3D リザルト
- **サウンド**: WebAudio によるプロシージャル合成(波音・水中音・リール・ドラグ音・スプラッシュ・カモメなど。音声ファイルなし)

## パフォーマンス

画質は端末に応じて自動選択(設定で 低 / 中 / 高 に変更可)。さらに実行中のフレームレートを見て描画解像度を自動で上下させます。

## ローカルで実行

ビルド不要です。ES Modules を使うため、簡易サーバーで配信してください:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

※ Three.js を CDN (jsdelivr) から読み込むため、インターネット接続が必要です。

## GitHub Pages で公開する

`.github/workflows/deploy-pages.yml` により、`main` への push で自動デプロイされます
(Settings → Pages → Source を **GitHub Actions** に設定)。公開URL: `https://<ユーザー名>.github.io/fishing/`
